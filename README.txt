USDT P2P — PWA для iPhone

Чтобы установить как веб-приложение на iPhone:
1. Загрузите содержимое этой папки на HTTPS-хостинг (например, GitHub Pages).
2. Откройте опубликованный HTTPS-адрес в Safari на iPhone.
3. Нажмите «Поделиться» → «На экран Домой».
4. Включите «Открывать как веб-приложение» (если этот переключатель показан), затем нажмите «Добавить».

Важно:
- Просто открыть index.html из приложения «Файлы» недостаточно для установки PWA.
- Для установки нужен HTTPS-адрес. После первого открытия сайт кешируется и основные функции могут работать офлайн.
- История хранится локально в браузере/веб-приложении на конкретном устройстве. Делайте «Экспорт JSON» для резервной копии.
- Не очищайте данные сайта, если не экспортировали историю.
